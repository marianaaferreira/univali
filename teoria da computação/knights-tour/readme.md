Como Executar o Projeto

Compilação:
Siga os passos abaixo para compilar o projeto utilizando o CMake:

mkdir build
cd build
cmake ..
make

Execução
Programa Principal:
./main

Testes:
./testes

Scripts de Automação
O projeto também possui scripts para facilitar a execução.
Antes de usar, é necessário dar permissão de execução:

chmod +x run.sh
chmod +x test.sh

Executar o programa via script
./run.sh

Executar os testes via script
./test.sh

Observações
Certifique-se de ter o CMake e um compilador C++ instalados na sua máquina.
Utilizar um ambiente Linux ou WSL para execução.
